Tactile Genesis

Simulating Tactile Sensors at Scale for Exploring Dexterous Task Learning

Anonymous authors

● Code ► Video

We integrate tactile sensors in Genesis physics simulation, exposing a representative set of tactile sensing abstractions — binary contact, contact depth, per-taxel force/torque, elastomer marker displacement, geometry-aware proximity, and a voxelized temperature field — under a common, configurable interface that runs across thousands of parallel environments on a single GPU.

Distillation Ablations

Every tactile student is distilled from the same privileged teacher for its hand and task, so the only thing that changes across a row is what the student can feel. Both views show checkpoint performance over distillation iterations: settled-goal success for repose and lift, and retained axial speed for continuous rotation. The first compares tactile types; the second holds the type at force_torque and varies the sensor imperfection profile. Wuji elastomer uses 250 internal surface-query samples instead of the default 500 without changing its taxel layout or observation dimension. Hover a mark for its value.
